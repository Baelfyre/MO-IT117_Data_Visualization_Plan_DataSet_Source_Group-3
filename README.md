# MO-IT117 Data Visualization Plan Dataset Source - Group 3

## Purpose

This repository stores the cleaned datasets and supporting reference files used by Group 3 for **MO-IT117 Data Visualization Techniques**.

The datasets will be used in **Google Colab** to explore useful variables, dataset combinations, patterns, and possible visualization techniques before the selected charts are implemented in **Tableau**.

The Colab analysis will help justify the final entries in the **Visualization Plan** and support the development of the Milestone 2 interactive dashboard.

## Datasets

The repository contains the cleaned 2024 Philippine Statistics Authority (PSA) datasets for:

- Internet Use by Gender and Region
- Internet Use by Age Group and Region
- Internet Use by Frequency and Region
- Internet Use by Type of Use and Region
- Network, Device, and Signal by Region

## Reference Files

Supporting project references include:

- Milestone 1: Data Cleaning and Insights Report
- MO-IT117 Project Proposal

## Planned Use

The datasets will be explored in Google Colab to:

- review available variables
- test useful dataset combinations
- identify meaningful patterns
- evaluate suitable chart types
- justify visualization choices
- prepare the final Visualization Plan
- guide the charts to be implemented in Tableau

## Data Source

**Philippine Statistics Authority (PSA), 2024**

This repository is intended for the group's academic data visualization planning and analysis.
